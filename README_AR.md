# 👑 مور — دليل تحويل اللعبة لتطبيق ونشرها في قوقل بلاي وآب ستور

هذا المجلد فيه **مشروع تطبيق كامل** (Capacitor) جاهز للبناء، مع كل ملفات المتجرين. صممته بحيث **ما تحتاج كمبيوتر ماك ولا Android Studio**: البناء يصير على سيرفرات مجانية (GitHub و Codemagic).

> ⚠️ **بصراحة:** ما أحد يقدر يضمن القبول ١٠٠٪ لأن المراجعة يسويها بشر في أبل وقوقل. لكن المشروع مجهّز ضد **كل أسباب الرفض المعروفة** (مذكورة آخر الدليل). وإذا انرفض، المراجع يكتب السبب بالضبط وتقدر تعدّل وترسل مرة ثانية.

---

## 📦 وش داخل المجلد

| المسار | وش هو |
|---|---|
| `www/index.html` | اللعبة نفسها (مور، بلوت، تركس، طرنيب) |
| `www/privacy.html` | صفحة سياسة الخصوصية (مطلوبة في المتجرين) |
| `assets/` | الأيقونة وشاشة البداية (تتولد منها كل المقاسات تلقائياً) |
| `capacitor.config.json` | إعدادات التطبيق (الاسم، المعرّف، الألوان) |
| `package.json` | الإضافات الأصلية: اهتزاز، نطق، إشعارات، مشاركة، زر الرجوع… |
| `.github/workflows/` | بناء نسخة **أندرويد** تلقائياً على GitHub |
| `codemagic.yaml` | بناء نسخة **آيفون** ورفعها لأبل تلقائياً على Codemagic |
| `store/` | الأيقونات، صورة الغلاف، لقطات الشاشة (آيفون، آيباد، أندرويد)، ونصوص المتجر والاستبيانات |

### المميزات الأصلية اللي أضفتها (عشان أبل ما تعتبره «موقع مغلّف»)
- 📳 **اهتزاز** مع الورق والتكويش والدبل والفوز
- 🗣️ **نطق أصلي** لأصوات الشخصيات من محرك الجوال
- 🔔 **تذكير يومي** بإشعار محلي (اختياري)
- 📤 **مشاركة** اللعبة من «ملفي»
- ⬅️ **زر الرجوع** في أندرويد (يقفل النوافذ ويسألك قبل ما تطلع من المباراة)
- 📴 **تشتغل بدون إنترنت**، والخطوط داخل التطبيق
- 📱 متوافقة مع **النوتش** وحواف الآيفون
- ⚙️ سياسة خصوصية، «عن اللعبة»، و«مسح بياناتي» داخل الإعدادات

## الخطوة ١ — الحسابات (مرة وحدة)

1. **قوقل بلاي:** سجّل في [Google Play Console](https://play.google.com/console) — **٢٥ دولار مرة وحدة**.
   - إذا سجّلت **حساب شخصي**: قوقل تشترط **اختبار مغلق مع ١٢ مختبِر لمدة ١٤ يوم متواصلة** قبل النشر للعامة. جهّز ١٢ شخص عندهم أندرويد من الحين.
   - إذا عندك **سجل تجاري** وسجّلت كـ **منظمة (Organization)**: ما يلزمك شرط الـ١٢ مختبِر، بس تحتاج رقم D-U-N-S (مجاني ويأخذ وقت).
2. **آبل:** سجّل في [Apple Developer Program](https://developer.apple.com/programs/) — **٩٩ دولار سنوياً**.
3. **GitHub:** سوّ حساب مجاني في [github.com](https://github.com).
4. **Codemagic:** سجّل دخول بحساب GitHub في [codemagic.io](https://codemagic.io) (فيه دقائق بناء مجانية كل شهر تكفي).

## الخطوة ٢ — ارفع المشروع على GitHub

1. في GitHub اضغط **New repository** ← سمّه `moor-app` ← اختر **Private** ← Create.
2. اضغط **uploading an existing file** واسحب كل محتويات هذا المجلد (فك الضغط أول).
   > ⚠️ مجلد `.github` يبدأ بنقطة وممكن يكون مخفي. إذا ما انرفع، في صفحة المستودع اضغط **Add file ← Create new file** واكتب الاسم `.github/workflows/android-release.yml` والصق محتوى الملف، وكرّرها للملف الثاني `android-make-key.yml`.
3. اضغط **Commit changes**.

## الخطوة ٣ — بناء نسخة أندرويد (قوقل بلاي)

### أ) مفتاح التوقيع (مرة وحدة بس)
1. في المستودع: **Settings ← Secrets and variables ← Actions ← New repository secret**
   - الاسم: `ANDROID_KEYSTORE_PASSWORD` — القيمة: كلمة سر قوية **واحفظها عندك**.
2. روح تبويب **Actions** ← اختر **«Android - إنشاء مفتاح التوقيع (مرة وحدة)»** ← **Run workflow**.
3. لما يخلص (علامة ✅) افتح التشغيل ← تحت **Artifacts** حمّل `moor-upload-key-SAVE-SAFELY`.
   - داخله ملفين. **احفظهم في مكان آمن (مثل Google Drive خاص)** — إذا ضاعوا ما تقدر تحدّث التطبيق بسهولة.
4. افتح ملف `upload.keystore.base64.txt` وانسخ كل النص ← سوّ Secret جديد:
   - الاسم: `ANDROID_KEYSTORE_BASE64` — القيمة: النص اللي نسخته.

### ب) بناء التطبيق
1. **Actions ← «Android - بناء نسخة قوقل بلاي (AAB)» ← Run workflow**.
2. بعد ~١٠ دقايق حمّل `moor-android-aab` من Artifacts ← داخله ملف `.aab` — هذا اللي ترفعه لقوقل.

### ج) قوقل بلاي كونسول
1. **Create app** ← الاسم: `مور: بلوت وتركس وطرنيب` ← اللغة: العربية ← Game ← Free.
2. عبّي **Store listing** من ملف `store/STORE_LISTING.md`، وارفع:
   - الأيقونة: `store/icon-512-googleplay.png`
   - صورة الغلاف: `store/feature-graphic-1024x500.png`
   - لقطات الهاتف: كل الصور في `store/screenshots/android/`
   - (اختياري) لقطات تابلت: `store/screenshots/ipad/`
3. عبّي **App content** (الخصوصية، الإعلانات، التصنيف، أمان البيانات، الجمهور) — **الإجابات جاهزة في `store/STORE_LISTING.md`**.
4. **Testing ← Closed testing ← Create track** ← ارفع ملف `.aab` ← أضف إيميلات الـ١٢ مختبِر ← أرسل للمراجعة.
5. بعد ما ينقبل، أرسل رابط الاشتراك للمختبِرين، **خلهم يثبتون اللعبة ويلعبون فيها كل كم يوم لمدة ١٤ يوم**.
6. بعد ١٤ يوم: **Apply for production** ← جاوب الأسئلة (عن الاختبار والملاحظات) ← وبعد الموافقة انشر في **Production**.

## الخطوة ٤ — بناء نسخة آيفون (آب ستور) بدون ماك

### أ) جهّز أبل
1. في [developer.apple.com](https://developer.apple.com/account/resources/identifiers/list) ← **Identifiers ← +** ← App IDs ← App ← Bundle ID: `com.moorgame.cards` ← Register.
2. في [App Store Connect](https://appstoreconnect.apple.com) ← **Apps ← + ← New App** ← iOS ← الاسم `مور: بلوت وتركس وطرنيب` ← اللغة العربية ← اختر نفس الـ Bundle ID ← SKU: `moor001`.
3. **Users and Access ← Integrations ← App Store Connect API ← +** ← الاسم `Codemagic` ← الصلاحية **App Manager** ← حمّل ملف المفتاح `.p8` (ينحمل مرة وحدة بس!) واحفظ **Issuer ID** و **Key ID**.

### ب) Codemagic
1. **Teams ← Integrations ← Developer Portal ← Connect** ← الاسم: `moor_asc` ← حط Issuer ID و Key ID وارفع ملف `.p8`.
2. **Add application** ← اختر مستودع `moor-app` من GitHub ← نوع المشروع: **Ionic Capacitor** ← بيقرأ ملف `codemagic.yaml` تلقائياً.
3. **Start new build ← ios-release**.
   - Codemagic يسوي شهادات التوقيع تلقائياً، ويبني التطبيق، ويرفعه لـ **TestFlight**.

### ج) أرسل للمراجعة
1. في App Store Connect افتح التطبيق ← عبّي المعلومات من `store/STORE_LISTING.md`.
2. ارفع اللقطات:
   - **iPhone 6.9"**: صور `store/screenshots/iphone/`
   - **iPad 13"**: صور `store/screenshots/ipad/`
3. **App Privacy** ← Data Not Collected. **Age Rating** ← جاوب None على الكل (النتيجة 4+).
4. اختر الـ Build اللي رفعه Codemagic ← الصق **Review Notes** من الملف ← **Submit for Review**.
5. المراجعة عادة من يوم لـ ٣ أيام.

> 💻 **إذا عندك ماك:** تقدر تبني بنفسك بدل Codemagic:
> ```
> npm install
> npm run setup
> npx cap open ios
> ```
> وبعدها من Xcode: Product ← Archive ← Distribute App.

## الخطوة ٥ — رابط سياسة الخصوصية (إلزامي في المتجرين)

1. افتح `www/privacy.html` وغيّر **`[ضع إيميل الدعم هنا]`** و **`[support email]`** لإيميلك.
2. انشرها برابط عام. أسهل طريقة:
   - سوّ مستودع **عام (Public)** جديد في GitHub اسمه `moor-privacy` ← ارفع الملف باسم `index.html`.
   - **Settings ← Pages ← Branch: main ← Save** ← بيعطيك رابط مثل `https://اسمك.github.io/moor-privacy/`.
3. حط هذا الرابط في خانة **Privacy Policy URL** في المتجرين (وفي أبل كمان كـ **Support URL**).

## الخطوة ٦ — المشتريات والاشتراك VIP 💳

اللعبة فيها **٣ باقات عملات** و**اشتراك VIP (شهري وسنوي)**. الكود جاهز، ويستخدم أنظمة الدفع الرسمية لأبل وقوقل فقط (هذا شرط إلزامي في المتجرين). المطلوب منك تسوي المنتجات في المتجرين **بنفس المعرّفات بالضبط** — الجدول والأسعار المقترحة في `store/STORE_LISTING.md`.

### أبل (App Store Connect)
1. **Business ← Agreements**: وقّع اتفاقية **Paid Apps** وعبّي البنك والضريبة. بدونها المشتريات ما تشتغل.
2. افتح التطبيق ← **Monetization ← In-App Purchases ← +** ← النوع **Consumable** ← سوّ الثلاث: `moor_coins_small` و `moor_coins_medium` و `moor_coins_large`.
   - لكل واحد: السعر، الاسم والوصف بالعربي، وارفع صورة المراجعة `store/iap-review-coins.png`.
3. **Monetization ← Subscriptions ← Create subscription group** اسمها `Moor VIP` ← أضف:
   - `moor_vip_monthly` بمدة **1 Month**
   - `moor_vip_yearly` بمدة **1 Year**
   - صورة المراجعة: `store/iap-review-vip.png`
4. أول مرة لازم ترسل المنتجات **مع نسخة التطبيق** للمراجعة: في صفحة النسخة، قسم **In-App Purchases and Subscriptions**، اختر كل المنتجات.
5. في **App Information** خلّ **License Agreement** على Apple Standard EULA، ورابط الشروط موجود أصلاً في الوصف الجاهز.

### قوقل (Play Console)
1. **Setup ← Payments profile**: سوّ ملف الدفع (حساب البنك).
2. ارفع نسخة AAB الجديدة على الاختبار المغلق أول، لأن قوقل ما تسمح لك تسوي منتجات قبل ما ترفع نسخة فيها الدفع.
3. **Monetize ← Products ← In-app products ← Create**: سوّ الثلاث (`moor_coins_small` و `moor_coins_medium` و `moor_coins_large`) وفعّلها **Active**.
4. **Monetize ← Subscriptions ← Create**:
   - `moor_vip_monthly` ← أضف **Base plan** شهري يتجدد تلقائياً (Auto-renewing, 1 month) ← Activate
   - `moor_vip_yearly` ← Base plan سنوي ← Activate
5. **License testing**: أضف إيميلك عشان تجرّب الشراء بدون ما ينخصم منك فلوس.

### مزايا VIP داخل اللعبة
كل الشخصيات والطاولات وظهور الورق مفتوحة، طاولة وظهر ورق ذهبي حصري، عملات ×٢ من كل فوز، ١٠٬٠٠٠ عملة هدية كل شهر، وشارة VIP.

> ✅ اللي سويته عشان تنقبل المشتريات: زر **استعادة المشتريات** في المتجر والإعدادات، نص التجديد التلقائي والسعر والمدة واضح قبل زر الاشتراك، روابط سياسة الخصوصية وشروط الاستخدام، رابط مباشر لإدارة الاشتراك، والعملات تنصرف على أشكال بس (ما فيه رهان ولا صناديق حظ).

## 🌍 الطاولات بالأعلام
فيه ١٦ طاولة عربية و١٣ عالمية وطاولة VIP. كل طاولة بألوان علمها، والعلم يطلع كشعار على حافة الطاولة، **مو تحت الورق**، احتراماً للأعلام.
- **السعودية:** سويتها «الأخضر السعودي» بشعار النخلة بدل العلم. العلم السعودي فيه الشهادة، واستخدامه على منتج تجاري أو لعبة ممنوع نظاماً، وفيه حساسية دينية.
- **العراق:** للسبب نفسه (عبارة «الله أكبر» في العلم) ما حطيته.
- **سوريا:** ما حطيتها لأن علمها تغيّر مؤخراً وفيه حساسية سياسية. تقدر تضيفها لاحقاً إذا تبي.

## 🔄 تحديث اللعبة لاحقاً
1. استبدل `www/index.html` بالنسخة الجديدة.
2. غيّر رقم الإصدار في `package.json` (مثلاً `1.0.0` ← `1.0.1`) وفي `const APPV` داخل `index.html`.
3. شغّل نفس خطوات البناء (GitHub Actions للأندرويد، Codemagic للآيفون). رقم البناء يزيد تلقائياً.

## ✅ ليش جهّزت المشروع بهالشكل (أسباب الرفض الشائعة وكيف تفاديناها)

| سبب الرفض | وش سوينا |
|---|---|
| **أبل 4.2 — «مجرد موقع مغلّف»** | لعبة كاملة بـ٤ ألعاب وذكاء اصطناعي، تشتغل بدون نت، ومعها اهتزاز ونطق وإشعارات ومشاركة أصلية |
| **مقامرة / مقامرة محاكاة** (قوقل تمنعها في بعض دول الخليج) | ما فيه رهان ولا عجلة حظ ولا صناديق عشوائية. العملات (المكتسبة أو المشتراة) تنصرف على أشكال وشخصيات بس، ومكتوب هذا داخل اللعبة وفي الوصف |
| **مشتريات خارج نظام أبل وقوقل** | كل الدفع عن طريقهم فقط، مع زر استعادة المشتريات وشروط الاشتراك واضحة |
| **سياسة خصوصية ناقصة** | صفحة جاهزة + داخل الإعدادات + «مسح بياناتي» |
| **جمع بيانات بدون إفصاح** | التطبيق ما يجمع شي ← الإجابات «No / Data Not Collected» |
| **التشفير (Export Compliance)** | مضاف تلقائياً `ITSAppUsesNonExemptEncryption = false` |
| **واجهة تنقص تحت النوتش أو أزرار ما تشتغل** | دعم كامل لحواف الشاشة، وكل الأزرار تشتغل، وما فيه «قريباً» أو روابط مكسورة |
| **أيقونة فيها شفافية (أبل ترفضها)** | الأيقونة بدون شفافية 1024×1024 |
| **رموز وطنية محمية** | شلت السيفين من رسمة النخلة على ظهر الورق عشان ما تشبه الشعار الوطني |
| **لقطات شاشة بمقاسات غلط** | مقاسات رسمية: آيفون 1290×2796، آيباد 2064×2752، أندرويد 1242×2208 |
| **إشعارات مزعجة** | التذكير اختياري ويطلب الإذن أول ما تفعّله |

### نصائح أخيرة
- **لا تغيّر المعرّف** `com.moorgame.cards` بعد أول رفع. إذا تبي معرّف خاص فيك (مثل `com.اسم_شركتك.moor`) غيّره الحين في `capacitor.config.json` و `codemagic.yaml`.
- **لا تضيف** لاحقاً رهان بالعملات أو صناديق عشوائية تنشرى بفلوس، لأنها تحوّل التصنيف لمقامرة.
- **لا تحط** في الوصف أو داخل اللعبة رابط دفع خارجي (مثل تحويل بنكي أو موقع)، لأنه سبب رفض مباشر.
- خلّ المختبِرين في قوقل **يفتحون اللعبة فعلاً** خلال الـ١٤ يوم، لأن قوقل تسأل عن تفاعلهم.
